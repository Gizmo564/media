How to get this into Outlook without it breaking
Best — works everywhere

Send it as a real HTML email

If your school/org sends newsletters through a mail platform (Mailchimp, Emma, Marketing Cloud, etc.), upload the downloaded .html file there directly. This is the only path that guarantees the colors, background art, and mobile layout all survive, because the file is delivered as true HTML instead of being retyped by Outlook's editor.

Good — sending straight from Outlook

Paste with "Keep Source Formatting"

  1. Click Download .html, then open that file in Chrome or Edge.
  2. Click anywhere in the page and press Ctrl+A then Ctrl+C.
  3. In Outlook, start a New Email, click inside the body, and press Ctrl+V.
  4. A small clipboard icon appears — click it and choose Keep Source Formatting (this is the step people usually miss, and it's why colors and backgrounds normally vanish).

This file inlines every color as both CSS and an HTML bgcolor attribute, and gives textured backgrounds a Word-safe fallback — so this route holds up far better than a template exported without those fixes.

About images from your computer

Embedded files vs. hosted links

Any image field has a Use a file from my computer button — pick a photo/logo and it travels inside the email itself as embedded data, no separate hosting needed. It's automatically resized so it doesn't bloat the file. This works well in Gmail, Apple Mail, and on phones, but classic Outlook desktop (Windows) often refuses to display embedded images — only a genuinely hosted link is guaranteed to show up there.

If this newsletter is going to Outlook desktop users, it's safer to host each image somewhere free and paste the link instead: imgbb.com, postimages.org, and Cloudinary's free tier all let you drag in a file and get a direct link back with no account required for the first two. Your school's own web/CMS storage (if you have any) works too.
